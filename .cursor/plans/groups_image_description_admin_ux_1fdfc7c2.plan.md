# תכנית: פונקציונליות קבוצות — תמונה, תיאור, הרשאות ו-UX

## טבלת הרשאות — מה כל חבר (כל member) יכול לעשות

**מצב נוכחי אחרי הרפקטור (GroupManage.tsx):**

| פעולה | כל חבר (כולל מנהל) | הערות |
|--------|----------------------|--------|
| **לצאת מהקבוצה** | כן | כרגע בפרונט: כפתור "צא מהקבוצה" מוצג **רק למי שלא מנהל** (בטאב חברים). אם רוצים שגם מנהל יוכל לצאת — צריך להציג את הכפתור גם למנהל ולוודא שבבקאנד יש העברת מנהלות לחבר אחר. |
| **לצפות בקבוצה** | כן | כותרת (שם, מספר חברים), טאבים נסיעות + חברים. |
| **חפש בקבוצה** | כן | כפתור בכותרת → מעבר ל־/search. |
| **הצע נסיעה לקבוצה** | כן | כפתור בכותרת → /create-ride עם state: { groupId }. |
| **לצפות בנסיעות הקבוצה** | כן | טאב "נסיעות" + Chips תאריך (הכל/היום/מחר/השבוע). |
| **לצפות ברשימת החברים** | כן | טאב "חברים" — רשימה + תג "מנהל"/"חבר". |
| **לצפות בתיאור הקבוצה** | (עתידי) | כשנוסיף שדה תיאור — כולם יראו (קריאה בלבד). |

**סיכום:** יציאה מהקבוצה היא הפעולה ה"משנה מצב" היחידה שפתוחה לכולם; כרגע ב-UI היא מוצגת רק למי שלא מנהל. שאר הפעולות הן צפייה או ניווט (חיפוש, הצעת נסיעה).

## טבלת הרשאות — מה רק מנהל יכול לעשות

| פעולה | מנהל בלבד | סטטוס נוכחי |
|--------|------------|-------------|
| העלאת תמונת קבוצה | כן | לעתיד — S3 GROUPS/<id>/ |
| עריכת תמונה (החלפה) | כן | לעתיד |
| מחיקת תמונת קבוצה | כן | לעתיד |
| הסרת חבר מהקבוצה | כן | **קיים** — תפריט ⋯ → "הסר" |
| שינוי שם הקבוצה | כן | **קיים** — טאב הגדרות |
| עריכת תיאור קבוצה | כן | לעתיד + הגבלת תווים |
| הוספת חברים (הזמנה/קישור) | כן | כרגע כפתור/מקום שמור, לוגיקה לעתיד |
| מחיקת קבוצה (soft delete) | כן | **קיים** כ־"מחק קבוצה" בהגדרות; לעדכן לבקאנד: סטטוס מחוק, כולם יוצאים |
| קידום חבר למנהל | כן | **קיים** — תפריט ⋯ → "קדם למנהל" |
| גישה לטאב "הגדרות" | כן | **קיים** — אייקון גלגל שיניים בכותרת + טאב הגדרות |

## S3 — מבנה תיקיות

- **תיקיות ראשיות:** `GROUPS/` ו־`USERS/`.
- **תת-תיקיות:** `GROUPS/<group_uuid>/`, `USERS/<user_uuid>/` (או להשאיר כרגע `avatars/` ליוזרים).
- תמונת קבוצה: `GROUPS/<group_id>/` (למשל קובץ יחיד או staging → worker כמו באווטאר).

---

## UX — רשימת קבוצות vs דף קבוצה

- **רשימת קבוצות:** תמונת קבוצה (או placeholder) ליד כל שם; **לא** גלגל שיניים; לחיצה על **שם** הקבוצה → מעבר לדף הקבוצה.
- **דף קבוצה:** גלגל שיניים רק כאן (למנהל) → מעבר לטאב הגדרות.
- **טאב חברים:** תג "מנהל" ליד מנהלים; "See More" → מודל עם רשימה מלאה + חיפוש.

---

## לוגיקות נוספות

- **מנהל יוצא:** אם אין מנהל אחר — לבחור חבר (למשל אקראי או הראשון ב־joined_at) ולהפוך למנהל.
- **מחיקת קבוצה:** סטטוס "מחוק" (או ENUM); קבוצה לא מוצגת לחברים, לא ניתן להצטרף; כולם "יוצאים".

---

## המלצה לגבי "צא מהקבוצה" למנהל

כדי שכל אדם (כולל מנהל) יוכל לצאת:
- להציג את כפתור "צא מהקבוצה" **גם למנהל** (למשל בטאב חברים או בהגדרות).
- בבקאנד: כשמנהל יוצא, אם יש לפחות חבר אחד — להעביר מנהלות לחבר אחר (למשל הראשון); אם אין — להחליט (למשל למחוק את הקבוצה או להשאיר ללא מנהל).
